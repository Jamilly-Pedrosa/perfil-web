# Perfil Web 

Este projeto é uma página de perfil pessoal desenvolvida com foco em boas práticas de desenvolvimento web, utilizando 
HTML semântico, CSS moderno e lógica de JavaScript pura, sem uso de bibliotecas ou frameworks externos.

## 🚀 Sobre o Projeto
Este projeto foi desenvolvido como parte das atividades de **Monitoria da disciplina de Programação para Web**. 
O objetivo é aplicar os conceitos fundamentais de desenvolvimento front-end, focando na criação de interfaces modernas, 
semânticas e funcionais através da manipulação direta do DOM e boas práticas de estruturação de código.

## .✦ Tecnologias Utilizadas

- **HTML5:** Estrutura semântica focada em acessibilidade e organização.

- **CSS3:** Flexbox para layout, variáveis CSS para manutenção, e design responsivo.

- **JavaScript:** Manipulação dinâmica do DOM, validação de campos em tempo real e interatividade de componentes.

## .✦ Principais Funcionalidades

- **Cards Interativos:** Destaque visual ao selecionar habilidades, com feedback imediato via JavaScript.

- **Formulário Dinâmico:** Validação de campos (Nome e E-mail) com mensagens de erro personalizadas.
  
- **Contador de Caracteres:** Monitoramento em tempo real do limite de caracteres no campo de mensagem com alerta visual.

- **Design Moderno:** Layout limpo e otimizado para uma experiência.
